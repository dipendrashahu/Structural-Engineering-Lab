# Structural Engineering Lab

A growing engineering platform by **Dipendra Shahu**, bringing together a professional portfolio and an interactive Engineering Lab.

## Project structure

- `index.html` — homepage and main navigation
- `portfolio/index.html` — project portfolio and case-study area
- `lab/index.html` — introduction to the Engineering Lab
- `css/style.css` — shared visual system and responsive styles
- `js/main.js` — lightweight navigation and footer behaviour
- `assets/` — identity and visual assets

## Run locally

No build tools or package installation are required.

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension if installed.

The site is built with plain HTML, CSS, and JavaScript so it can be hosted as a free static website.

## Development principles

- Keep the portfolio factual: publish projects, qualifications, and experience only when details are confirmed.
- Develop the Engineering Lab progressively around selected engineering questions.
- Explain the assumptions, units, methods, and limitations of future interactive experiences.
- Treat interactive engineering outputs as learning aids, not substitutes for complete analysis, applicable code checks, or professional engineering judgement.
