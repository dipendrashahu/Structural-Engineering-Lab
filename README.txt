# Structural Engineering Lab — homepage redesign

This is a replacement for the current homepage, using a minimalist architectural/editorial visual direction.

## Files
- `index.html` — page structure and content
- `css/style.css` — colours, layout, typography and responsive styling
- `js/main.js` — mobile navigation and current footer year

## Install in the existing VS Code project
1. Extract this ZIP.
2. Copy `index.html` into the root of your existing project and choose **Replace**.
3. Copy the `css` and `js` folders into the same project root. If asked to merge folders, choose **Merge**.
4. Keep `index.html`, `css`, and `js` at the same level.
5. Open `index.html` in your browser and refresh.

The page uses Google Fonts when internet is available; it falls back to system fonts offline.
